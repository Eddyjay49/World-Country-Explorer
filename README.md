# 🌍 Country Explorer

A responsive country explorer built with JavaScript, Fetch API, and async/await.

## Features

- 🔎 Search for any country
- 🏳️ Display country flag
- 🌍 Display country information
- 🗺️ Display neighboring country
- ⏳ Loading state
- ❌ Error handling
- 📱 Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await

## What I Learned

This project helped me practice working with APIs, asynchronous JavaScript, DOM manipulation, error handling, and responsive design.
